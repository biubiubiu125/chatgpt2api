# 独服生图并发自适应提效设计

**Goal:** 让图片队列的生成并发按 CPU / 内存自动推算默认值，不再依赖写死的 64 / 128，保留可手工覆盖的外层硬阀。

**Architecture:** 图片队列配置在实例创建时根据运行时资源计算默认并发；生成并发默认值来自机器资源和运行时容量提示，硬上限只做兜底；总线程保护线根据同样的机器信息自动推算，避免把独服闲置在过低默认值上。资源控制器继续保留 CPU、内存、Swap、数据库连接池、磁盘和线程数的动态降速逻辑，不改总体保护链路。

**Behavior:**
- `IMAGE_QUEUE_GENERATION_CONCURRENCY_CAP` 只作为外层硬阀，默认值放宽到 99999。
- `IMAGE_QUEUE_GENERATION_CONCURRENCY` 未配置时由 CPU / 内存 / 运行时容量提示自动推算。
- `IMAGE_QUEUE_ABSOLUTE_GUARD` 未配置时由同一组机器指标自动推算，不再固定 128。
- 手工显式配置仍然优先生效，但会被硬阀和基本范围约束。

**Out of Scope:**
- 不改图片任务协议。
- 不改资源控制器的降载策略主体。
- 不改集群拓扑和数据库结构。
